# Terminal Mini Projects

Two beginner-friendly Python command-line apps.

## 1. Number Guessing Game
- 3 difficulty levels, limited attempts, input validation, replay option
- Run: `python number-guessing-game/guess.py`

## 2. To-Do List
- Add, view, complete and delete tasks, saved to `tasks.json`
- Run: `python todo-cli/todo.py`

## Requirements
Python 3.10+, no external libraries.
